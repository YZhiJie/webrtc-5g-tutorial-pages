浏览器与网络基础自查 ​

WebRTC 是一套浏览器 API，但它背后触及操作系统、网络栈、编解码、NAT 穿透等深层机制。动手前，先做一次知识自查。

0.1 必过的三道门槛 ​

门槛为什么必须最低标准
HTTPS / localhostgetUserMedia、RTCPeerConnection 等 API 仅在安全上下文下开放本地开发用 http://localhost 或 https://127.0.0.1；部署必须 HTTPS
ES6+ 异步WebRTC 所有操作几乎都是 Promise / Event 驱动能读懂 async/await、addEventListener、状态机（RTCPeerConnection.iceConnectionState 等）
WebSocket 或同域信令WebRTC 需要"信令通道"交换 SDP 和 ICE 候选会起一个简单的 WebSocket 服务，或用 Firebase/SignalR 等托管方案

0.3 网络概念速查 ​

WebRTC 涉及的网络协议栈：

┌─────────────────────────────────────┐
│  应用层  WebSocket(信令) / HTTP(S)  │
├─────────────────────────────────────┤
│  会话层  DTLS (WebRTC 媒体加密)     │
├─────────────────────────────────────┤
│  传输层  SRTP (RTP + AES)           │
├─────────────────────────────────────┤
│  网络层  UDP (主) / TCP (回退)       │
├─────────────────────────────────────┤
│  NAT    穿透 / STUN / TURN          │
└─────────────────────────────────────┘
术语一句话解释
NAT路由器把内网 IP 映射成公网 IP，导致两台内网机器无法直接互通
STUN告诉客户端"你在公网长什么样"（反射地址）
TURNSTUN 失败时的中继服务器，所有流量经它转发
ICE"STUN + TURN + 直连"的综合候选选择机制
RTP实时传输协议，承载音视频数据包
SRTP加密版 RTP，WebRTC 强制使用
SDP会话描述协议——双方交换"我支持什么编解码、我的网络地址"

0.4 Node.js + WebSocket 快速上手 ​

WebRTC 的信令服务器最小实现：

bash
mkdir signaling-server && cd signaling-server
npm init -y && npm install ws
js
// server.js
import { WebSocketServer } from 'ws'

const wss = new WebSocketServer({ port: 8080 })

wss.on('connection', (ws) => {
  console.log('peer connected')
  ws.on('message', (data) => {
    // 把消息转发给所有其他客户端
    wss.clients.forEach((client) => {
      if (client !== ws && client.readyState === 1) {
        client.send(data.toString())
      }
    })
  })
})
console.log('Signaling server running on ws://localhost:8080')
bash
node server.js

这就是你完成模块 7（基础通话）所需的全部信令服务器代码。复杂项目再上 Socket.IO / Mediasoup / Janus。

0.6 FAQ ​

  • Q：必须用 Chrome 吗？ 本教程以 Chrome/Edge 为主（市场占比最大、特性最完整）。Firefox/Safari 的差异在模块 10 详细对比。
  • Q：内网能测 WebRTC 吗？ 能。同局域网两台设备、localhost、127.0.0.1 都被视为安全上下文。NAT 穿透环节需要公网 STUN 服务器，可先用 Google 提供的免费 STUN（stun:stun.l.google.com:19302）。
  • Q：WebRTC 会用到哪些 Node.js 依赖？ 信令服务器：ws 或 socket.io；TURN：coturn（C 程序）；SFU：mediasoup（C++ + Node）/ janus（C）/ livekit（Go）。
  • Q：完全不会网络能学吗？ 能。本教程在遇到新概念时会同步讲基础。但 NAT 穿透、UDP vs TCP、拥塞控制这几块需要一点耐心。
